SPAWT — Direction canonique

Showcase de la direction « Magazine éditorial × Mode contextuel » telle qu'établie dans le kit canonique documentation/ux/ (brandbook v1.0 + spawt-tokens.css + wireframes + mid-fi). Ce fichier remplace la version précédente (6 directions inventées) — la direction n'est pas à choisir, elle est déjà explorée et aboutie dans le kit.

⚠ Polices réelles : Klinsman (display) + Gotham (body) — non libres, fournies dans documentation/ux/fonts/. Ce showcase HTML utilise des fallbacks (Georgia / Futura) pour l'aperçu. Couleurs = exactes (spawt-tokens.css).

Ce que ce showcase établit

  • Direction = « Magazine éditorial × Mode contextuel » — déjà explorée et aboutie dans documentation/ux/. Pas un choix à faire, un canon à suivre.
  • Palette canonique : Or #C8A44E · Vert Chat #2D6B4F · Blanc cassé #FAFAF8 · gradients gr-night / gr-gold — depuis spawt-tokens.css.
  • Typo : Klinsman (display) + Gotham (body) — fournies dans documentation/ux/fonts/.
  • Nav 5 onglets : Feed · Carte · [FAB + Spawter] · Meute · Palais.
  • Light-first + moments gr-night : le sombre est un traitement de moment (notif, célébration, carte spawter, paywall, splash), pas un thème.
  • ✅ Drifts kit ↔ PRD ↔ Contrat — 11/11 tranchés le 2026-05-14 (voir « Canonical Sources & Reconciliation » dans ux-design-specification.md) : OTP only (D1) · « paws » gardé non-convertible + « reconnaissances » non-public, sous garde-fous Contrat (D2/D3) · 1 badge Sprint 1 (D4) · Tanière = cercle privé, favoris renommés (D5) · « Le Guet » pas « VTC » (D6) · note 1-5 (D7) · axes Palais PRD (D8) · réservation/Visa hors V1 (D9) · onboarding = OnbMidfi cartes visuelles (D10) · Home = HomeD (D11).
